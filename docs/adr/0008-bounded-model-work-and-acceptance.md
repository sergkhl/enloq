# Bound model work and the initial acceptance campaign

This ADR set the first acceptance campaign's call, money and write ceilings,
and a fixed $1 daily limit for model calls with full-context reservations that
stayed charged until settled. The campaign is closed.
[ADR 15](0015-owner-controlled-processing-memory-and-prompts.md) owns the
Daily Budget (owner-set, receipts plus a flat estimate for an unknown outcome,
never raised automatically) and the Concurrency Limit,
[ADR 48](0048-members-on-the-shared-service.md) gives each member their own
budgets, and [ADR 4](0004-acceptance-quality-feedback.md) owns how finite
checks are bounded and recorded.
